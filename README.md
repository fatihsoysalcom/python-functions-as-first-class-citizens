# Python Functions as First-Class Citizens

This example demonstrates Python's core concept of functions as first-class citizens, a key difference from Java's method-centric approach. It shows how Python functions can be assigned to variables, passed as arguments to other functions, and returned as values from functions, enabling more flexible and modular code.

## Language

`python`

## How to Run

Save the code as `main.py`. Open a terminal in the same directory and run `python main.py`.
